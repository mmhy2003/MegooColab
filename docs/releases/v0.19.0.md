MegooColab 0.19.0 makes steering an agent quicker, has agents check current library documentation, gives agent replies the full width on large screens too, and puts MegooColab's icon on a mockup's tab.

## New

- **The comment box sends to the task's agent by default.** While a task isn't in a Done column, and you may message its agent, the "Send to <agent>" switch starts on, and after each message it is on again. You no longer click it before every instruction, and an instruction can't go out by mistake as a comment the agent never reads.
  - To write a comment just for people, turn the switch off for that message: after you send it, the switch is back on. Mentioning the agent with @ still sends to it.
  - In a Done column the box starts as an ordinary comment, as before. So does it for people who can't message the agent.
- **Agents check library documentation before relying on memory.** Every agent session (task steps, reviews, freestyle chats, scheduled jobs, answers to other projects and Knowledge Base drafts) is now told: when you need facts about a library, framework, SDK, API or command-line tool, look in the Knowledge Base first, then use Context7 if you have it, even for well-known libraries. A session without Context7 carries on as before. The instruction is built in, so projects with their own edited instructions get it too.

## Improved

- **Agent replies use the full width on every screen.** In 0.18.3 a reply's time moved next to the agent's name on a phone. Tablets and laptops now get the same layout: the time sits after the name or at the end of an event line, and replies, run summaries, fix-round summaries and pull request excerpts reach across the whole Activity column. In an open task on a laptop, a reply gets about a third more width.

## Fixed

- **A mockup opened full screen shows MegooColab's icon on its tab.** The tab used to show no icon, because the mockup page is locked down and the browser couldn't load the site's icon for it. A mockup that sets its own icon keeps it.

## Upgrading

Pull and restart as usual. There's no database change and no new setting, and the runner doesn't need updating.

To let agents use Context7: add Context7 to your Tool Hub (if it isn't there yet), turn on **Safe in read-only runs** for it, and push it to your machines. Brainstorming, planning and reviews run read-only, so without that setting their Context7 calls are refused and they carry on without it.
