MegooColab 0.14.6 stops the activity thread from showing an agent's reply a second time as raw Markdown.

## Fixed

- **An agent's reply no longer shows up twice, the second time as raw text.** When an agent ended a turn, the activity thread showed its reply as formatted Markdown and then again in the "finished: …" line as flat text, with raw `**`, backticks and run-together bullets. This happened in chats and on tasks alike.
  - **The "finished" line now just says the agent finished** when its reply is already in the thread above it.
  - **When the reply isn't in the thread** (for example, a run from before this release whose messages aren't loaded), its summary shows under the "finished" line as Markdown, in the same cyan-edged box as an agent's reply.
  - **A pushed fix's summary** ("Fixed and pushed to PR #N") is written by the agent too, and now renders as Markdown instead of plain text.
  - The dashboard's recent activity says "*agent* finished" instead of repeating the whole reply.
  - As before, an agent's text can't add raw HTML to the page.

## Upgrading

Pull and restart as usual. Nothing else changes, and runner 0.8.0 stays current.
