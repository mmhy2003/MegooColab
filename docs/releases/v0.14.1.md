MegooColab 0.14.1 shows an agent's replies as formatted text in chats and in a task's Activity, and checks for new MegooColab versions every hour.

## Improved

- **An agent's reply reads as formatted text.** What an agent says in a chat or a task's Activity used to show as one long grey line: `**` and backticks showed as typed, there were no line breaks, and a long reply was cut into pieces every few seconds, sometimes mid-word. Now:
  - **One reply, one message:** the pieces of a reply are joined back together. A command the agent runs, or another of its runs, starts a new message.
  - **Shown as Markdown:** bold, lists, code, headings, tables and links. It's one size smaller than a design or plan (13 px instead of 14 px), in a block with a thin cyan edge so it reads as the agent's reply.
  - **Links open in a new tab.**
  - **Unchanged:** status lines such as "started working" or "ran pytest" keep their plain one-line look.
  - **Safe as before:** raw HTML is never shown, and an image the agent links shows as a link instead of loading.
- **New versions are found sooner.** MegooColab now asks GitHub for the latest release every hour instead of every 6 hours, and the page asks your server every 15 minutes. An "update available" notice now appears within about an hour and a quarter of a release. `UPDATE_CHECK=false` still turns the check off.

## Upgrading

Pull and restart as usual. Nothing else changes, and runner 0.8.0 stays current.
