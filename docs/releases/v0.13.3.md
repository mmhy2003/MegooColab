MegooColab 0.13.3 fixes chats that got stuck on **waiting: decide the escalation** with nothing to decide it with.

## Fixed

- **An escalated chat can now be decided in the chat.** When a chat's round stopped and needed a decision, for example after the agent's runs failed 3 times in a row, the chat said "waiting: decide the escalation" but showed no buttons. A chat's round has no task page of its own, so there was nowhere else to decide it either, and the round stayed stuck.
  - **The escalation shows at the end of the conversation,** with its reason and the same choices a task has: **Retry**, **Pause**, and **Accept** where a task allows it (**Mark merged** when an agent's merge couldn't be confirmed).
  - **"waiting: decide the escalation" in the chat's header is now a button** that takes you there, like the chat's other waiting notes.
  - Someone who can't decide sees the reason, and who decides.
- **A message sent while a chat waits on an escalation now retries the round.** It used to wait for the agent's next run, which never came. The line under the message box now says "Retry with your message: the agent starts again and reads it." Messages already waiting go out with the retried run too.
  - The one exception is an agent's merge that couldn't be confirmed. Its Retry only reads the pull request again, so a message still waits for the agent's next run.

## Upgrading

Pull and restart as usual. Nothing else changes, and runner 0.8.0 stays current.
