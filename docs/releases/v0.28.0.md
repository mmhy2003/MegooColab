MegooColab 0.28.0 opens attachments in a full-screen viewer instead of downloading them. Images, PDFs, text files, audio and video are shown right in the page.

## New

- **A full-screen viewer for attachments.** Clicking a file shows it in the page:
  - **Images and SVGs:** zoom with − and + (50% to 300%), or click to switch between 100% and 200%.
  - **PDFs:** shown in the browser's own PDF viewer.
  - **Text files:** shown as plain text. A large file shows its first 1 MB, with a note saying so. HTML and Markdown files show their source; they are never rendered.
  - **Audio and video:** play in the page.
  - **Every other file** keeps a Download button.
- **Moving between files.** With several files, use the arrows, the thumbnail strip at the bottom, or ← and → on the keyboard. Escape closes the viewer. Checked images and PDFs can also be opened in a new tab.
- **The viewer opens everywhere attachments show:**
  - a task's Attachments list, on the task page, in the task drawer and in chats. Each file there also gets its own download button.
  - the images under a comment, an answer or a chat message;
  - the images you've added to a message, before you send it.
- **A missing file says so.** If a file was deleted, the viewer says "This file is no longer available." A file it can't display says "This file can't be shown here.", with Download.
- **On a phone** the viewer fills the screen, and the arrows sit at the bottom corners.

## Upgrading

Pull and restart as usual. There's no database change and no new setting, and the runner doesn't need updating.
