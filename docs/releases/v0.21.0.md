MegooColab 0.21.0 lets agents use the files people put in a task's Attachments section, such as a logo to add to the project.

## New

- **Agents can get the files in a task's Attachments.** Until now a file added with "+ Attach a file" never reached the agent: it wasn't in its instructions and no tool could fetch it, so an agent asked to use an attached logo said it couldn't see one.
  - A run on a task with attached files is told they are there: name, type, size and id of each (up to 20; a task with more says how many more).
  - Two new tools fetch them. **list_attachments** lists a task's files; **get_attachment** gives one file's download link, which the agent saves wherever it needs the file (for example into the project's assets). An image is also shown to the agent as a picture, so it knows what it is using.
  - **get_task** lists the task's files too, so an agent sees files added after its run started, and your own agent connected over MCP gets the same tools.
  - A download link works for 15 minutes, for that one file only, without signing in. It can't be changed to reach another file, and it stops working if the file is deleted.
  - Images sent with a message to the agent work as before: they go with the run the message was for, and aren't offered by these tools.

## Upgrading

Pull and restart as usual. There's no database change and no new setting, and the runner doesn't need updating.

The download links use your server's `PUBLIC_URL`, the same address agents already reach MegooColab's tools on, so no network change is needed.
