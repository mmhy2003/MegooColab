MegooColab 0.18.2 stops build steps from ending unfinished when an agent's tests take a long time.

## Fixed

- **Agents wait for long test suites instead of ending their run.**
  - **What went wrong:** a full test suite that took more than a few minutes was left running in the background, and the agent ended its turn saying it would read the result when the tests finished. The run ends with the turn, so the tests stopped with it and nobody read their result. After one nudge the task asked you with "The agent ended its run without finishing the step."
  - **Now:** every session that changes the repository is told that background commands stop when its turn ends. It runs long commands, such as a full test suite, in the foreground, waits for them however long they take, and never ends its turn to wait. The nudge after an unfinished step names this mistake too. Read-only sessions are unchanged.
  - **Together with runner 0.8.1,** Claude Code agents can no longer start background commands at all, and a single command may run for up to 3 hours. See the runner's release note.

## Upgrading

Pull and restart as usual. There's no database change and no new setting. Update the runner on each machine to 0.8.1 as well: without it, Claude Code still stops a foreground command after 10 minutes. A task already waiting with "The agent ended its run without finishing the step" continues when you press Retry.
