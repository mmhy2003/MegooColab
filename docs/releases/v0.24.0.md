MegooColab 0.24.0 shows what every agent is working on, marks the browser tab when you have unread notifications, and shows the server's version in the sidebar.

## New

- **The Agents pages show everything an agent is working on.** An agent that runs several things at once now lists all of them, not just one.
  - **My agents:** the agent's card has a "Working on" section listing each run with its link, status and running time. It's hidden while the agent runs nothing.
  - **Admin → Agents:** the "Working on" column shows the newest run as a link, with the rest behind a "+N more" button, and the status says how many runs are in use, for example "3 of 3 running".
  - Only the agent's owner and admins see its runs. A run in a project you can't open shows its title without a link.
- **The browser tab shows unread notifications.** While you have unread notifications, the MegooColab favicon carries a small red bell and the tab title starts with the count, for example `(3) Projects · MegooColab` (`99+` above 99). Both clear once everything is read.
- **The sidebar shows the server's version.** A quiet "v0.24.0" sits at the foot of the sidebar, next to Collapse, and at the bottom of the phone menu. Everyone signed in sees it, and clicking it opens that release's notes on GitHub in a new tab. A server built from source shows `dev`, without a link.

## Improved

- **Dashboard → Running now is easier to read.** Each row starts with the link to the task, chat or question, with the agent, status and time on a second line. A long agent name now shortens instead of pushing the link out of view.

## Fixed

- **Reading a notification updates your other tabs and devices.** Before, marking a notification read, or using "Mark all read", left the bell count unchanged in your other MegooColab tabs until they were reloaded.
- **A cron run in Running now links to its cron.** Before, it showed as a question with a broken link.

## Upgrading

Pull and restart as usual. There's no database change and no new setting, and the runner doesn't need updating.
