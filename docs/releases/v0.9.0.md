MegooColab 0.9.0 lets an agent work on several tasks and chats at once, adds **OMP** as a third agent program, and sends notifications to **Telegram**. **Settings › My agents** is rebuilt as three tabs that stay short however many projects you have, and the dark theme gets a new look.

## New

### Several runs at once per agent
- Each agent has a **Runs at once** setting from 1 to 3, on **Add agent** and in the agent's settings. Raise it and the agent takes up to that many tasks and chats together, each in its own session.
- You can raise or lower it any time. Lowering it never stops a run in progress: those finish as they are, and nothing new starts until the agent is under its new limit.
- The agent shows how many runs it has going ("2 of 3 running"), and is **Busy** only when every slot is taken.

### OMP agents
- **OMP** (Oh My Pi, the `omp` command) joins Claude Code and Codex as an agent program. Add an OMP agent like any other; it runs with your own OMP setup, models and sign-ins on that machine.
- OMP agents need **runner 0.5.0** and **OMP 18.12.6 or newer** on the machine. Until both are there, the agent says why it can't run: **Update the runner to use OMP agents.**, **omp not found**, or **OMP 18.12.6 or newer is needed**.
- OMP agents get your Tool Hub tools: **Push** installs MCP servers and skills for OMP too, and each run gets the hub MCP servers it may use.
- **Settings › My agents › Runner** shows how to install OMP and sign in to your model providers, for Windows, macOS and Linux.

### Telegram notifications
- An admin sets up one Telegram bot for the site in **Admin › Settings › Telegram**: create it with @BotFather, paste its token, and MegooColab checks it with Telegram before saving it. The token is stored encrypted and never shown again.
- In **Settings › Notifications**, press **Connect Telegram**, then **Start** in Telegram, and your own chat is linked. **Disconnect Telegram** undoes it.
- A **Telegram** column joins In app, Email and Push, per kind of notification. When you first connect, Telegram switches on for the kinds you already get as push, or for **needs you** and **mentioned** if you get none.
- Messages carry the notification's title and short text, and an **Open in MegooColab** button when your site's address is public https.
- It works on a server that can't be reached from the internet: MegooColab asks Telegram for new messages itself. Messages only go out; replying in Telegram does nothing.

### My agents, in tabs
- **Settings › My agents** has three tabs: **Agents**, **Tools** and **Runner**. Each shows a short list, with the chosen item beside it; on a phone the list fills the screen and the item opens full screen with Back.
- **Agents**: each agent's settings, and its projects as a searchable list, one line per project and ten at a time. **+ Add project** adds one in a single row and saves at once; folders are edited in place, and removing asks first. The **⋯** menu has **Rename**, **Answer mode** (now changeable after an agent is created) and **Delete**.
- **Tools**: your machines, each with what a push would change, beside its Tool Hub panel. On a phone the **Push** button stays on screen.
- **Runner**: your machines with their runner's version and agents, and each machine's commands. **+ Add a machine** walks you through it: name the machine and its runner token is made on the spot and filled into the sign-in command, then install, check, keep it running, and **Add an agent on it** once it connects.

## Improved

- **A new dark theme, Chrome & neon:** neutral graphite with cyan and pink as the only neon. The light theme is unchanged.
- **Notifications are read when you act on them:** comment on a task, approve or reject a design or plan, reply in a chat, answer a question, or change the task, and your unread notifications about it are marked read. Just opening it leaves them as they are.

## Fixed

- **@mentions in task comments** show as **@Name**, highlighted, instead of the raw `@[Name](user:…)` code. Backspace next to a name removes the whole name.
- **The logo stays at the top of the sidebar** while a long menu scrolls, on desktop and in the phone menu.

## Upgrading

Pull and restart as usual; the database is updated on start. Running several sessions at once works with any runner. OMP agents need **runner 0.5.0** on their machine.
