MegooColab 0.3.0 makes long tasks easier to get around, with buttons to jump to what needs you and to follow an agent as it works, and shows tables and diagrams in agent documents the way they were meant to look.

## New

### Getting around a task
- The task drawer and task page have buttons in the bottom-right corner.
- **↑** goes back to the top.
- **↓** goes to the newest Activity and keeps following it while an agent works: each new entry scrolls into view, and "● Following live" shows in the corner.
  - Following stops as soon as you scroll up to read something. What arrives meanwhile is counted on the ↓ button instead of moving the page.
  - Scrolling back to the bottom yourself starts following again.
- **"N waiting on you"** appears when something on the task needs your decision: a design or plan to approve, an open agent question, a stuck workflow, or a code review to mark merged.
  - Each click goes to the next one and highlights it for a moment. Keyboard focus moves there too.
  - An agent question further back than the loaded Activity is still found: earlier entries load until it shows.
  - The button goes away when nothing is waiting.

### Diagrams
- Mermaid diagrams are drawn, wherever MegooColab shows formatted text: descriptions, comments, design and plan documents, questions and the Knowledge Base.
  - A diagram the agent quoted inside a larger code block is drawn too, with the text around it kept as code.
  - Each diagram has a **Diagram / Code** switch, so its exact text can still be read and copied.
  - A diagram with a mistake, or a very large one, shows its code and says why it couldn't be drawn.
  - Diagrams follow the light or dark theme. On a phone, a wide diagram keeps a readable size and scrolls sideways.

## Improved
- Tables have a grid and a shaded header row, instead of reading like loosely aligned text. A wide table scrolls sideways inside its own box rather than stretching the page.
