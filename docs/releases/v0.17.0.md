MegooColab 0.17.0 gives every email the app's look, and sends a pull request with merge conflicts back to its agent to resolve.

## New

- **Every email in the app's look.**
  - **Which emails:** invitations, password resets, the two-factor notice, every notification and the test email.
  - **The look:** a dark brand bar with the logo, MEGOOCOLAB and your organization's name, then a white card with a coloured tag, a clear heading, the message and a button.
  - **Notifications** show the task's key and title, a tag and colour for their kind (Needs you, Assigned, Mentioned, Agent offline, Question waiting, Agent replied), and a link to change which emails you get.
  - **The footer** says why the email came.
  - **Mail apps in dark mode** show a dark card with the app's neon colours.
  - **Every email still has a plain-text copy,** for mail apps that don't show HTML. The logo comes from your server's public address (`PUBLIC_URL`); if a mail app blocks images, the wordmark still shows.

## Improved

- **A pull request the reviewing agent can't merge because of conflicts goes back to the task's agent.** This applies to projects whose pull requests an agent reviews.
  - **When the merge is refused:** the reviewer approves the pull request, but the host refuses the merge because the base branch has moved on. The reviewer now says so.
  - **The send-back round:** the task goes back to its own agent. It merges the base branch into the task branch, resolves the conflicts keeping what both sides intended, records each conflicted file and how it was resolved, and runs the full test suite. It then pushes to the same pull request, and the reviewer reviews and merges again.
  - **What the agent never does:** it never rebases or force-pushes. If its attempts don't make the tests pass, it pushes nothing and says why.
  - **In the activity:** "Sent back to its agent: merge conflict on PR #12 (round 1 of 3)". It shares the existing limit of 3 send-back rounds per pull request.
  - **Other refusals,** such as branch protection or failing checks, still come to you.
  - **The built-in review and fix instructions are updated on start** wherever nobody customised them.

## Upgrading

Pull and restart as usual. There's no database change, and runner 0.8.0 stays current.
