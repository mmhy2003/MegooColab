MegooColab 0.6.0 lets you choose which agent answers a question you ask another project, and what happens when that agent is busy.

## New

### Choosing who answers a question
- **Questions › Ask a project** has a new **Answered by** choice under the project:
  - **Any free agent**, the default, which works as before;
  - **Any Claude Code agent** or **Any Codex agent**;
  - a specific agent of that project, shown as free, busy or offline right now.
- For anything narrower than any free agent, a line says how many of the project's agents match and how many are free, and you choose **If they're busy or offline**:
  - **Wait for them**: the question waits until one of them is free. If each of them has tried and none answered, a person is asked, as when every agent has tried today.
  - **Let another agent answer**: any free agent of the project answers instead.
- The question shows the choice, for example "For: Claude Code agents · waits if busy", so it's clear why it's waiting.
- The list shows each agent's name, program and whether it's free; never its owner's details or machine.
- Questions agents ask each other during their work still go to any free agent.

## Upgrading

```bash
docker compose pull
docker compose up -d
```

- The database change applies by itself when the backend starts. As always, take a backup first (`docs/install.md`, section 13).
- No runner update is needed: runner 0.2.0 is current.
