MegooColab 0.2.0 lets your agents live on more than one computer, and adds push notifications that reach your phone or desktop even when MegooColab is closed.

## New

### One runner per computer
- Each agent now belongs to a machine: the access token of the computer it runs on. Pick it in the new **Machine** field under **My agents** (and in the Add agent dialog).
- A runner lights up and runs only the agents linked to the token it signed in with. With Claude Code and Codex on two laptops, starting the runner on one laptop brings only that laptop's agents online.
- Several computers can be online at the same time. Before, a second runner for the same person disconnected the first.
- Tasks go to the agent's own machine and wait for it when it's off. A runner disconnecting, reconnecting or sending stray messages never touches another machine's work.
- **Access tokens** lists the agents linked to each token, and warns how many will be unlinked when you revoke one.
- The agent's status, problems and the ↑ runner-update arrow now come from that agent's own machine. The owner and admins see the machine's name next to the status dot.

### Push notifications
- Notifications can now also arrive as push, on your phone or computer, even when MegooColab is closed.
- Under **avatar → Notifications**, turn push on for each device you use. The browser asks your permission only when you click **Turn on**. Your other devices are listed there, and you can remove any of them.
- Choose which kinds of notification you want as push in the new **Push** column. Every kind starts unticked.
- A push shows the same title and text as the bell. Tapping it opens the task, and repeats about the same task replace each other instead of piling up.
- There's nothing for an admin to set up: the server makes its own push keys on first use. Push needs HTTPS. On iPhone and iPad it works in the app added to the Home Screen.

## Improved
- Signing out stops push on that device. A password reset or a deactivation stops it on all of that person's devices, and also unlinks their agents (their tokens are revoked).
- Changing an agent's machine while it is running a task is refused, so a running task never loses track of the computer it runs on.
- The notification settings table fits narrow phone screens.

## Upgrading

```bash
git pull
docker compose pull
docker compose up -d
```

- **Link your agents to their machines.** After the update every existing agent shows **Not linked to a machine** and stays offline until you link it.
  1. Under **Access tokens**, create one token with the **Runner** scope per computer, or reuse the one already there.
  2. On each computer, sign the runner in with that computer's token: `megoocolab-runner login --url … --token …`.
  3. Under **My agents**, set each agent's **Machine** to its computer's token.
- Any agent task still running when you update is marked failed, because no runner can claim it any more. Start it again once the agent is linked.
- Runner 0.1.0 works with this release. Runner 0.1.1, released alongside it, is recommended.
- Push needs the server to reach the browsers' push services (Google, Mozilla, Apple, Microsoft) over the internet. If it can't, the bell and email keep working as before.
- Database changes apply by themselves when the backend starts. As always, take a backup first (`docs/install.md`, section 13).
