MegooColab 0.23.1 is a maintenance release that comes with runner 0.11.0; the server works as in 0.23.0.

## Improved

- **The backend's tests can run on their own containers.** A rate-limit test that assumed Valkey on port 6379 now uses the Valkey the tests are configured with, so the whole backend suite runs under `megoocolab-runner services run test`. Nothing changes for people using MegooColab.

## Upgrading

Pull and restart as usual. There's no database change and no new setting. Updating the runner to 0.11.0 is optional: it adds per-worktree test services for agents' checks.
