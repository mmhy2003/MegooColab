MegooColab 0.8.0 adds the **Tool Hub**: keep your MCP servers and skills once, share them without their keys, and push them to your machines. It also makes the Knowledge Base and Memory easier to get around, with a Back button that returns where you came from.

## New

### Tool Hub: your MCP servers and skills, kept once
- **Tool Hub** in the sidebar, with three shelves: **Mine**, **Shared with me** and **Everyone**, and a search box.
- **Add MCP**: an MCP server reached by a web address, or run as a command, with its headers or environment variables.
  - Mark any value as a **secret**. Secrets are stored encrypted, are never shown again, and you set them on the tool's page.
  - Put a secret inside the address or an argument as `${NAME}`.
  - A command can differ per system: a command for Windows, Linux or macOS when one setup doesn't fit all.
  - **Safe in read-only runs**: turn it on for tools that only read (a docs reader, say), and agents may use them while they brainstorm, plan or review.
- **Add skill**: upload a skill as a `.zip` or a folder with a `SKILL.md` at its top. Its name and description come from the `SKILL.md`. Files that run code are flagged with the systems they need.

### Sharing, never the keys
- Share a tool with your teams, with people, or with everyone on MegooColab. Its setup and files go out; its secrets never do.
- Before you take someone's tool, you see everything it holds: its setup, every file, and a warning when it runs code on your machine. Secrets show as **needs <NAME>**, for you to fill in with your own.
- **Add to my library** takes a copy. When the person who shared it improves it, you see **Update available** and choose when to **Take update**. Your own keys are kept.
- **Make it my own** turns a copy into a tool of yours, which you can then change and share.
- A value that looks like a key, left in plain setup, holds back sharing until you mark it secret or confirm it isn't one. A tool already shared can't be edited to hold one.

### Pushing tools to your machines
- **Settings › My agents** has a panel per machine: tick the tools that machine should have, press **Push**, and its runner installs them for every agent program on it (Claude Code and Codex). Each tool shows what the runner reported: installed, update ready, changed on this machine, made by hand on this machine (with **Take over**), key missing, failed, and more.
- Pushes wait for an offline machine and are delivered, with your library as it is then, when it comes back.
- **Import from this machine** brings in the MCP servers and skills you set up by hand. Values that look like keys are masked and pre-marked secret, and you pick what to bring in.
- **Default set**: mark tools **In my default set** and turn on **When I add an agent on a new machine, install my default set there**.
- The **Tool Hub** item in the sidebar shows a dot when one of your machines doesn't match your library.
- Agents get the tools: hub skills reach Claude Code runs, and MCPs marked safe in read-only runs work in every step.

### Admins
- **Admin › Tool Hub** lists every tool shared beyond its owner, with **Stop sharing** and **Remove**. Secrets and private tools are never shown.
- **Remove** takes a tool off every shelf; everyone who added it sees **removed by an admin**, and machines change only when their owner pushes.
- **Settings › Tool Hub** can turn off sharing with everyone.
- Sharing, stopping sharing and removing are recorded in the audit log.

## Improved

### Getting around
- **The top bar's trail shows names**, never IDs: project names, task keys, chat titles, teams, questions, folders and documents. On a phone a long trail folds to its first and last step.
- **Back returns where you came from** in the Knowledge Base and Memory: to your search results, the folder you were in or the entity you came from, named on the button.
- **The Knowledge Base's folder tree stays beside the document you read**, with your place in it. Folders you opened stay open, and **←** / **→** step through the folder's documents.
- **Memory's entity list stays beside the entity**, with your filter, so hopping between entities is one click.
- On a phone, the tree or list sits behind a **Files** or **Entities** button.

## Upgrading

Pull and restart as usual; the database is updated on start. Pushing tools to machines needs **runner 0.4.0** on each machine; a machine with an older runner says **Update the runner to use the Tool Hub.**
