MegooColab 0.16.0 lets a freestyle chat's agent turn a topic you talked through into a task on the board, and gives the New chat dialog a project picker you can search.

## New

- **A freestyle chat's agent can create tasks on the chat's project.** When you go back and forth with the agent about a topic, it can turn that topic into a task to review and run later.
  - **When you ask** ("make a task for this"), it creates the task right away.
  - **When it thinks a topic deserves its own task,** it asks you first. It ends its reply with the title it would give the task and what the task would cover, and creates it only once you say yes.
  - **Where the task lands:** in the project's first column with nobody assigned. Creating it never starts any work.
  - **What the task says:** the agent writes the description from the conversation: what was decided, what's still open, and the files or links that matter. The description ends with a link back to the chat.
  - **In the chat:** a line like "laptop-claude created PAY-42: Retry webhook deliveries" links to the new task, and the agent's reply gives its key.
  - **Limits:** only on the chat's own project, and only in freestyle chats. Workflow chats and tasks on the board can't create tasks.

## Improved

- **Pick a new chat's project from a list you can search.** The Project field in the New chat dialog now looks like the Chats page's project picker, for a single project.
  - **Closed,** it shows the picked project's key and name, or "Choose a project".
  - **Open,** a search box matches a project's key or name and highlights the match, and the picked project has a ✓.
  - **Picking a project** closes the list.
  - **On a project's own Chats tab,** the field stays fixed to that project, as before.

## Upgrading

Pull and restart as usual. There's no database change, and runner 0.8.0 stays current.
