MegooColab 0.11.0 lets you **write Knowledge Base documents with an agent**. Give one of your agents a brief, and it writes a draft. Then ask it for changes ("add a rollback section", "shorten the intro", "drop the FAQ") and fix things yourself, until you're happy and save. Nothing reaches the Knowledge Base until you do.

## New

### Write with an agent
- **Starting a draft:** **Write with an agent** sits beside **New document** in a space, and beside **Edit** on a document you may edit. Choose:
  - the **agent**;
  - what the document should be (or, for an existing one, what to change);
  - tasks (`PAY-12`) and documents it should **read first**, read with your own access;
  - for a new document, the folder to **save into**.
- **Which agents:**
  - **A project's space:** the project's agents you may use, as in chats. They work in a copy of the project's code and may read it to write accurately, but change nothing.
  - **A team's or the organization's space:** your own agents, working in an empty folder of their own.
- **The writing page** shows the draft as it will look, beside your conversation with the agent.
  - The agent's first answer is a whole draft. Each request after that changes it, in one place or several.
  - The agent says in a sentence or two what it did, and may ask you a question.
- **Its changes are marked** until you decide:
  - **added** in green, **changed** in amber (old words struck through, new ones shown), **removed** in pink;
  - each with the request it came from, and **Keep** and **Undo**;
  - **Keep all** and **Undo all** for the last request.

  Sending the next request keeps what you didn't undo.
- **Aim a request** by selecting text in the draft: the request is then about that text ("About: selected text in 'Prerequisites'"). Otherwise it's about the whole document.
- **Type in it yourself:**
  - **Edit text** opens the Markdown editor with its preview, and keeps any open changes first.
  - The agent works on the draft as you left it and keeps your edits. Your own edits are never marked.
  - While the agent writes, the draft is read-only, with **Stop**. A stopped turn changes nothing.
- **Drafts are kept.** Close the tab and come back: **Knowledge Base › My drafts** lists them. A document you have a draft of says "You have an unsaved draft with <agent> · Open". You have one draft per document, and nobody else sees it.
- **Save to KB…** saves the draft as a revision credited to you with the agent ("Written with <agent>" unless you write a summary). It tells you how many changes you haven't reviewed.
- **If someone saved a newer version meanwhile,** you choose:
  - **Show what changed**;
  - **Ask the agent to bring it in**;
  - **Save over it anyway**, after a confirmation.
- **Discard draft** deletes the draft and its conversation.
- **Notifications:** you're notified when the agent has updated your draft.
- **On a phone,** the draft and the conversation are two tabs.

### The agent's instructions are yours to edit
**Admin › Methodology** has a new **Knowledge base** tab with the instructions the writing agent follows.

## Improved

- A document's history now credits a revision written with an agent as "<person> with <agent>" (it said "<person> (via <agent>)").

## Upgrading

Pull and restart as usual; the database is updated on start.

- **Runner 0.7.0** is needed on an agent's machine for that agent to write drafts. The agent list in **Write with an agent** marks agents whose runner needs updating. Everything else works with runner 0.6.0.
