MegooColab 0.29.0 lets agents put more than text in front of you: they can ask with a form, show a result as a card in the thread, and give a cron run a panel of numbers and charts. All of it is drawn with MegooColab's own components and theme, never with code from the agent.

## New

- **Questions with a form.** An agent can ask several related things in one question as a form instead of one question each. A form holds text and number fields, checkboxes, choice pickers, sliders and date pickers, with the checks the agent asked for (required, a pattern, a length, a number, an email).
  - **Send answer** stays off while a field fails its check. The agent gets your answer back as data.
  - **Answer in your own words instead** is always offered, for when the form misses the point.
  - Once answered, the form stays in the thread, read-only, with what you sent.
- **Cards in the thread.** An agent can show a result as a card next to its reply in a task's or a chat's Activity: stat tiles, tabs, and lists with links to tasks.
  - Every card has a title and a short text. Notifications, search and later agent runs read those, and the page shows the text wherever the card can't be drawn.
  - A task's cards are found by search, like its comments.
- **Panels on cron runs.** A cron that watches numbers can report them as a panel of stat tiles and bar or line charts. The run's page draws it above Summary, Findings and Checked. A run without a panel looks the same as before.
  - A chart holds up to four series, drawn in the theme's chart colours. Hover a point to see its value, or switch to a table of the same numbers.
  - The next run of the cron gets the last panel back, so the agent can keep the layout and add a point to each trend.
- **Two more chart colours** in both themes, so a chart can show four series.

## Improved

- The default instructions say when an agent should use a form, a card or a panel, and that it should still reply in text. Agents learn the details from the new tools `get_form_guide`, `get_card_guide` and `get_panel_guide` when they need them.

## Upgrading

Pull and restart as usual. The update adds database columns for question forms and cron panels, and a table for cards. They are applied automatically when the server starts. There's no new `.env` setting, and the runner doesn't need updating.

If you customised the instruction texts (Freestyle, Cron, Finish and the other stages), your agents aren't told about forms, cards and panels until you add it to your texts. The defaults include it.
